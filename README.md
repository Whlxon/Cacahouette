# Le Tirage des Lutins

Une application web permettant d’ajouter des membres à une liste, de générer une cacahuète pour chaque personne et de leur envoyer un e-mail à l’adresse indiquée.

## Fonctionnalités

- Ajouter des membres à une liste
- Renseigner une adresse e-mail pour chaque membre
- Générer une cacahuète pour chaque personne
- Envoyer un e-mail à chaque membre
- Consulter la liste des membres ajoutés
